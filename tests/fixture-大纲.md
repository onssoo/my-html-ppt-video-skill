# 小样本 · 验收用

- 受众：内部验收
- 用途：工具链自测
- 目标时长：1 分钟
- 主线：用小样本证明解析与预检按规范工作
- 素材：fixture-src.md

## P1 封面标题写结论
- 版式：封面：kicker + 主标题 + 副标题（模板 cover.html）
- 信息点（1）：
  1. 主标题：小样本验收
- 时长：12 秒
- 讲述要点（3–5 条，每条注明出处）：
  1. 这是自测样本（§1）
  2. 不参与出片（§1）
  3. 用完即可删（§1）
## P2 一、自测章节
- 版式：章节页：大序号 + 章节标题 + 一句话导语（模板 divider.html）
- 信息点（1）：
  1. 序号 01
- 时长：12 秒
- 讲述要点（3–5 条，每条注明出处）：
  1. 这是章节页（§1）
  2. 不计信息点密度（§1）
  3. 时长取固定值（§1）
